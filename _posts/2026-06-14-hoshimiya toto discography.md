Inspired by [this video](https://www.youtube.com/watch?v=DmoN_DG1yKk), I wanted to go through Hoshimiya Toto's discography, but it's all over the place, so I made this for personal use.

This is inspired by those fanmade collaborative "tracker" google sheets that some artists have, where hardcore fans keep a comprehensive list down to the most obscure releases. Unlike actual trackers though, this is not collaborative nor comprehensive - I have no knowledge in IDs, and I have no interest in the super old stuff (she's a vtuber, ffs).

## about
her aliases
- Hoshimiya Toto / Toto Hoshimiya / 星宮とと
- totonee / ととねぇ - "Creator of toto hoshimiya. Produced toto hoshimiya as her own virtual clone."

bands
- Stargaze Shelter - band consisting of Hoshimiya Toto, Totonee, and gaze//he's me. named after its members (star and gaze) and [shelter](https://www.youtube.com/watch?v=fzQ6gRAEoy0)
- TEMPLIME - band consisting of KBSNK and DJ Tempura, frequent collaborator from the beginning until POP-AID era

## sources
- [official list](https://hoshimiyatoto.com/#discography) - "modern" Hoshimiya Toto starting from Timesurf (basically, all of her best stuff)
- [rateyourmusic](https://rateyourmusic.com/artist/%E6%98%9F%E5%AE%AE%E3%81%A8%E3%81%A8)

<script>
const table = document.querySelector("table");
const checkboxes = document.querySelectorAll("#typeFilters input");

const typeColumn = [...table.querySelectorAll("th")]
  .findIndex(th => th.textContent.trim() === "Type");

function filterRows() {
  const enabled = [...checkboxes]
    .filter(cb => cb.checked)
    .map(cb => cb.value);

  table.querySelectorAll("tbody tr").forEach(row => {
    const type = row.cells[typeColumn].textContent.trim();
    row.hidden = !enabled.includes(type);
  });
}

checkboxes.forEach(cb =>
  cb.addEventListener("change", filterRows)
);
</script>
