Kaho

An AI assistant that doesn't try to make you obselete

As PKM knowledge bases grow, users struggle to maintain connections between notes and rediscover relevant information. Existing AI features address this poorly, focusing on content generation rather than supporting the synthesis and linking processes that make note-taking valuable. Kaho is an Obsidian plugin that aims to assist the users' workflows while preserving those processes.

Github

Features

Wikilink suggestions

Suggests text that can be linked to a note in your vault

Smart suggestions sidebar

Carefully designed AI-powered suggestions while you type (similar notes, tag suggestions, folder suggestions, note split suggestions, and "try revisiting..." suggestions)

AI agent

Self explainatory :)

Natural language search

Stop guessing keywords and search in natural language

Orphan rescuer

Finds notes with no links, then suggest similar notes to help you get started with linking them.
